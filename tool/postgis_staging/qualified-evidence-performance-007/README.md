# Performance007 evidence

This package retains every top-level raw experiment result, failed attempt, measurement harness and derived summary produced before checkpointing. Source/build directories and dependency links are excluded. The full original-index entries and protected owner-file hash inventory remain in the task report directory; preservation-preintegration.json records their comparison without bundling unrelated owner content.

Start with final-measurement-summary.json, moderate-matching-summary.json, critical-path-accounting.json and review-007-code.json. Consult evidence-corrections.json and trace-segments.json before interpreting historical labels or the combined append-only trace. The final report distinguishes reproduction, balanced causal comparisons and final-current-main integration.

Harnesses are records of this exact local fixture, with fixed report/source paths, synthetic identities, emulator endpoints and retained local databases. They are not generic hosted deployment commands. Reusing them requires reproducing the documented isolated source/runtime/fixture and replacing task-local paths deliberately; no cloud or production endpoint is authorized. Original006 reference helpers and invalid-reference attempts remain in qualified-evidence-review-006 and its referenced report directories.

Builds/consumer qualification use the frozen source manifest next to the report. Final source digest and the final local image are separate from this evidence index. INDEX.json hashes every package file except itself and binds the adjacent report and source-manifest bytes. Post-commit/remote/backlog results are appended only to the external CHECKPOINT.json to avoid a self-referential commit identity.
